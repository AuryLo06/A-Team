# Auryona Lomas — Personal Website

My personal portfolio site, created for ISDS 3100 at Louisiana State University. It introduces who I am, my experience, and the projects I've worked on, and it's built with HTML, CSS, and a little JavaScript.

Live at [aury.site](https://aury.site).

## Reflection

Vague requests like "make it more professional" or "give it more personality" led the agent to redesign the whole site in directions I didn't want, and I went back and forth between looks that felt either too toy-like or too plain. Once I asked for side-by-side mockups first (three cream and tan background options, then four box styles), I could point at exactly what I liked, and we converged in a couple of steps. Because every color lives in a CSS variable at the top of `styles.css`, each chosen option was a small, targeted change instead of a rewrite. Directing an agent works best with concrete choices to react to, not adjectives.
